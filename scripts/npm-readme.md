# dufresne

[![CI](https://github.com/enqrose/dufresne/actions/workflows/ci.yml/badge.svg)](https://github.com/enqrose/dufresne/actions/workflows/ci.yml)
[![npm version](https://img.shields.io/npm/v/dufresne.svg)](https://www.npmjs.com/package/dufresne)
[![license: MIT](https://img.shields.io/npm/l/dufresne.svg)](https://github.com/enqrose/dufresne/blob/main/LICENSE)

Copy small, dependency-free TypeScript utilities straight into your project
instead of installing a package for them — shadcn/ui, applied to plain
functions, algorithms and types.

```bash
npx dufresne add intersection
npx dufresne list
```

90 items: underscore-style utilities, popular algorithms/data structures/
patterns, and the well-known TypeScript utility-types canon — each with a
JSDoc header, a test, and (where checkable) a doctested example.

**Full command reference, configuration and the complete catalog:**
👉 **https://github.com/enqrose/dufresne#readme**
